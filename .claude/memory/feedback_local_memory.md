Никогда не писать файлы на диск `C:` (включая системную папку персистентной памяти
`C:\Users\...\.claude\projects\<project>\memory\`) без личного одобрения пользователя.
Вместо этого использовать локальную память внутри рабочего проекта: `./.claude/memory/`
(в данном случае `F:\ProjectTemplate\.claude\memory\`), с тем же форматом
(`MEMORY.md` как индекс + отдельные файлы с frontmatter).

**Why:** пользователь считает C: диск/системные пути вне рабочего проекта запретной
зоной для любых незапрошенных записей — включая штатный механизм памяти харнесса,
который по умолчанию пишет туда без вопроса. Первый инцидент: файл
`project_purpose.md` был создан в системной папке памяти без спроса, пользователь
потребовал удалить его и правило зафиксировать как глобальное.

**How to apply:** в этом проекте (и по аналогии — в любом другом, где действует та же
логика "не трогать C: без спроса") персистентная память ведётся в `./.claude/memory/`
рядом с кодом проекта, а не в стандартном системном пути. Если понадобится
межпроектная память (то, что нужно помнить между разными репозиториями на диске F:),
пользователь сообщит об этом явно — не создавать её самостоятельно.
