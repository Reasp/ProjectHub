## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Реализация полноценного встроенного интерактивного терминала на базе PTY/xterm.js с поддержкой параллельных сессий Claude Code в контексте каждого проекта, мульти-вкладок прямо внутри интерфейса приложения и автоматической синхронизацией списка незакоммиченных изменений на вкладке Git.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [x] #1 Встроенный интерактивный терминал xterm.js с поддержкой PTY и интерактивного ввода/вывода (TUI, ANSI, стрелки, клавиши) работает прямо внутри окна ProjectHub
- [x] #2 Поддержка мульти-вкладочного режима: создание нескольких независимых вкладок терминалов для разных или одного проекта
- [x] #3 Кнопка быстрого запуска Claude Code ('+ Claude Code') автоматически запускает интерактивную сессию claude в директории текущего проекта (cwd)
- [x] #4 Кнопка запуска обычного shell ('+ Terminal') для работы с PowerShell/CMD/Bash в корне проекта
- [x] #5 При создании, изменении или удалении файлов через Claude Code список незакоммиченных файлов на вкладке Git обновляется в реальном времени с отображением diff и stage/commit
- [x] #6 Фоновые сессии терминалов продолжают непрерывно работать при переключении между вкладками и проектами
<!-- AC:END -->

## Final Summary

<!-- SECTION:FINAL_SUMMARY:BEGIN -->
Реализован встроенный интерактивный мульти-терминал с поддержкой параллельных сессий Claude Code и shell-оболочек:
- Создан PTY-сервис `electron/services/ptyService.ts` на базе `node-pty` с поддержкой ConPTY на Windows.
- Разработан компонент `PtyTabTerminal.tsx` и обновлен `TerminalPanel.tsx` с мульти-вкладками, индикатором активности и кнопками '+ Claude Code' и '+ Shell'.
- Добавлена кнопка быстрого запуска Claude Code в `Header.tsx`.
- Расширен `gitService.ts` для непрерывного отслеживания файлов проекта chokidar-вотчером с мгновенной передачей события `git:changed`, что обеспечивает актуализацию списка незакоммиченных файлов на вкладке Git в реальном времени.
- Приложение полностью пересобрано в portable исполняемый файл `release/ProjectHub 0.1.0.exe` и `release/win-unpacked/ProjectHub.exe`.
