# ADR-0001: Выбор архитектуры и технологического стека ProjectHub

- **Статус**: Принято (Accepted)
- **Дата**: 2026-08-28
- **Автор**: Команда ProjectHub

---

## 1. Контекст и Проблема

Пользователю требуется единая десктопная панель управления проектами (аналог SourceTree / GitHub Desktop, но для проектного управления, бэклога `Backlog.md`, базы знаний RAG и локальных dev-серверов). Все проекты стандартизированы по шаблону `F:\ProjectTemplate` и содержат обвязку на базе Node.js / Python (RAG, MCP-серверы, скрипты процессов).

Необходимо выбрать архитектуру и технологический стек, которые обеспечат:
1. Автономное десктопное приложение (без зависимости от внешнего веб-браузера).
2. Полную и бесшовную интеграцию с существующим кодом шаблона `ProjectTemplate` на Node.js.
3. Надежное управление локальными процессами и файловой системой (чтение/запись markdown задач, сканирование директорий, запуск серверов).
4. Высокую скорость разработки и премиальный UI/UX (Канбан, терминал, Markdown-редактор).

---

## 2. Рассмотренные варианты

1. **Electron + Vite + React 19 + TypeScript**:
   - Единая экосистема Node.js/TypeScript.
   - Прямой вызов существующих библиотек (`@lancedb/lancedb`, `@modelcontextprotocol/sdk`, `child_process`).
   - Кроссплатформенность из коробки (Windows, macOS, Linux).

2. **Tauri v2 + React + Rust**:
   - Легковесный размер бинарника.
   - Требует компилятор Rust и усложняет вызов Node.js инфраструктуры (необходим Node-sidecar или дублирование логики).

3. **Web-сервер + Браузер (Next.js / Express)**:
   - Не удовлетворяет требованию автономности без внешнего браузера.

---

## 3. Решение

Выбран стек **Electron + Vite + React 19 + TypeScript + Tailwind CSS v4**.

### Ключевые компоненты решения:
1. **Main Process (Node.js)**:
   - Отвечает за сканирование диска на наличие проектов, мониторинг файловой системы (`chokidar`), парсинг задач (`gray-matter` + `zod`), запуск и трекинг dev-серверов (`node:child_process` + `tree-kill`), запуск RAG-поиска.
2. **IPC Preload Layer**:
   - Строго типизированный `contextBridge` API (`window.api.projects`, `window.api.tasks`, `window.api.processes`).
3. **Renderer Process (React 19)**:
   - Современный UI на Tailwind CSS v4 + Lucide Icons + @dnd-kit + @xterm/xterm + React Markdown.

---

## 4. Последствия и Преимущества

### Положительные:
- 100% переиспользование существующих скриптов и алгоритмов `ProjectTemplate`.
- Быстрый цикл разработки без переключения контекста языков программирования.
- Надежный контроль фоновых процессов на всех поддерживаемых ОС.
- Богатый выбор готовых UI-компонентов для десктопных панелей.

### Ограничения и компромиссы:
- Потребление оперативной памяти (~80-120 МБ), что является приемлемым для рабочей станции разработчика.
