## Context

Проект имеет полный локальный гейт качества (`validate-docs`, `check-index`, ESLint, Vitest,
`tsc`, `vite build`, `check-bundle`), но не имеет CI: каталог `.github/` отсутствует, и гейт
выполняется только на машине разработчика. Сборки: Windows `dir` и `portable`, macOS `dmg`
и `zip` без подписи и нотаризации, Linux-таргета нет. Автообновления нет, обновление это ручная
замена portable-архива. Crash-репортов нет, логи main-процесса пишутся в файл и никуда не
уходят. Токен встроенного MCP-сервера генерируется в памяти и меняется при каждом запуске,
поэтому конфиг внешнего Claude Code протухает.

Для ADE, который стоит на нескольких компьютерах, это означает разные версии на разных ПК,
несовместимый протокол федерации и невозможность отладить падение на удалённой машине.

## Decision

1. **GitHub Actions** с матрицей `windows-latest`, `macos-latest`, `ubuntu-latest`:
   на pull request и push в `master` выполняется `npm ci`, `npm run build` (весь локальный гейт),
   артефакты `pack:*` сохраняются; на тег `v*` выполняется `dist` и создаётся GitHub Release с
   бинарниками и `latest.yml`/`latest-mac.yml` для обновлений.
2. **Автообновление через `electron-updater`** с провайдером GitHub Releases. Для Windows
   добавляется таргет `nsis` (portable не поддерживает обновления и остаётся как вариант «без
   установки»). Для macOS обновления требуют подписи: пока сертификата нет, канал обновлений для
   macOS показывает уведомление о новой версии со ссылкой, без автоустановки. Для Linux
   добавляется `AppImage`.
3. **Проверка версии протокола федерации** при соединении хостов: несовместимые версии
   получают понятную ошибку и предложение обновиться.
4. **Crash-репорты локальные**: `crashReporter.start({ uploadToServer: false })`, дампы и
   `main.log` доступны в UI («Диагностика», кнопка «Собрать архив логов») и отправляются только
   вручную. Это соответствует [[decision-7]].
5. **Персистентный токен MCP-сервера** генерируется один раз, хранится в `safeStorage` и
   пересоздаётся только по действию пользователя, чтобы внешние конфиги Claude Code и Cursor не
   протухали. Токен показывается в UI с кнопкой копирования и отзыва.
6. **Ветка `master` защищена**: слияние только через PR с зелёным CI. Правило 9 CLAUDE.md
   (коммиты только по запросу пользователя) сохраняется.

## Consequences

- Плюс: одинаковые версии на всех ПК, воспроизводимые сборки, автоматическая проверка каждого PR.
- Плюс: обновление в один клик на Windows, что важно при частых релизах ADE.
- Минус: подпись macOS и Windows требует сертификатов и денег; до их появления часть
  пользователей увидит предупреждения SmartScreen и Gatekeeper.
- Минус: CI на трёх ОС собирает нативные модули (`node-pty`, LanceDB) дольше; кэш `npm` и
  `electron-builder` обязателен.
- Реализация: TASK-58.
