## Context

[[decision-16]] п. 4 ввёл учёт стоимости по таблице цен `agentCost.ts` с переопределениями в
`<userData>/agent-pricing.json`, а [[decision-26]] п. 3 требует, чтобы цены были редактируемыми данными:
UI-редактор, импорт из OpenRouter, нулевая цена локальных моделей. До TASK-70.4 было так:

- `agentFleetService.getPriceTable` читал файл один раз на процесс. Правка файла вступала в силу только после
  перезапуска, а UI не было, только ручное редактирование JSON.
- Стоимость считалась в трёх местах по-разному. Swarm брал таблицу с переопределениями. Claude CLI в AI Studio
  (`claudeBridgeService`) брал встроенную таблицу без переопределений. API-путь AI Studio (`aiAgentService`)
  стоимость не считал вовсе, поэтому ревьюер Arena получал `costUsd` только от OpenRouter.
- Признак «локальный» был у профиля (`LlmProfile.local`, [[decision-39]]) и в снимке слота
  (`AgentSlotState.providerInfo.local`, [[decision-40]]), но в цене не участвовал. Локальная модель считалась по
  имени: `qwen` без цены давал «—», а модель с ценой в таблице — платную сумму.
- У пресета Ollama и прежнего провайдера `ollama` был `streamUsage: false`. В стриме usage не приходил, поэтому
  у локальных агентов были только `tokensEstimated = chars / 4` и стоимость «—» (замечено в TASK-70.5).

Факты, проверенные при реализации (2026-09-19):

- **Ollama 0.34.0** (localhost, `qwen2.5:7b-instruct`) принимает `stream_options.include_usage` и присылает
  последний чанк с `choices: []` и `usage`, включая `prompt_tokens_details.cached_tokens`. На повторе запроса с
  тем же префиксом было 1679 закэшированных токенов из 1680. Без `stream_options` usage в стриме нет.
- **Ollama 0.31.2** (192.168.1.11, `ornith:35b`, рассуждения и tools) тоже принимает флаг и присылает usage, но
  без `prompt_tokens_details`: кэш эта версия не сообщает.
- **OpenRouter** `GET https://openrouter.ai/api/v1/models` отвечает без ключа, хотя документация описывает схему
  с ключом. 446 моделей пришли одной страницей (`links.next: null`). `pricing.prompt`/`completion` и необязательные
  `input_cache_read`/`input_cache_write` — строки в USD за токен. У роутеров (`openrouter/auto`) цена `-1`.
  96 id содержат `:` (`:free`, `:batch`, `:thinking`). У 69 моделей есть `pricing.overrides` с
  `min_prompt_tokens` (200 000, 272 000): это тарифы длинного контекста.
- **Anthropic** (скилл claude-api, данные на 2026-06-24): встроенные цены совпадают с первопартийными тарифами. У
  текущих моделей (Opus 4.7, 4.8, 5 и новее) 1M контекста идёт по стандартной цене без надбавки за длинный контекст.

Рассмотренные варианты:

1. **Источник для нулевой цены — `price-table` с ценой 0.** Отвергнуто. Нулевая цена в таблице привязана к имени
   модели, а бесплатность — к провайдеру: `qwen` у облачного сервиса платная, та же модель в локальном Ollama нет.
   К тому же «0 по таблице» неотличим от ошибки пользователя, который вписал ноль.
2. **Новое значение `costSource: 'local'`.** Выбрано: UI и экспорт показывают «$0.00 (локальная)», а не «—».
3. **Порог и множитель длинного контекста в `ModelPrice`.** Отвергнуто. Порог применяется к одному запросу, а usage
   агента суммируется по ходам tool-loop, по событиям Claude CLI и по итерациям цикла «до готовности». Применить
   порог к сумме нельзя: десять запросов по 50 тысяч токенов превысили бы порог 200 тысяч. У текущих моделей
   Anthropic надбавки нет. Выдумывать множители для других вендоров нельзя. Если понадобится, считать нужно
   по каждому ответу до суммирования; это отдельная задача.
4. **Автообновление цен из OpenRouter при старте.** Отвергнуто: противоречит local-first ([[decision-7]]) и
   [[decision-16]]. Сеть — только по кнопке.
5. **Импортировать весь список OpenRouter одним действием.** Отвергнуто: 350+ записей засоряют переопределения и
   перекрывают встроенные цены без ведома пользователя. Пользователь выбирает модели галочками.
6. **Показывать для платной модели стоимость по оценке токенов.** Отвергнуто: догадку нельзя выдавать за стоимость,
   и бюджет по ней срабатывал бы ложно. Оценка токенов показывается с пометкой, а стоимость остаётся неизвестной.

## Decision

1. **Источники стоимости**: `provider` → `price-table` → `local` → `unknown` (`CostSource`). `local` — стоимость 0,
   потому что провайдер работает на машине пользователя. `priceUsage(usage, model, table, { local })`:
   стоимость провайдера не перетирается, локальный провайдер даёт 0 и `local`, оценка у платной модели даёт
   `unknown` без стоимости, иначе цена берётся из таблицы или `unknown`. При сложении `addUsage` ранжирует
   источники так: `unknown` < `local` < `price-table` < `provider`.
2. **Признак «локальный» берётся у провайдера, не у модели**: профиль — `LlmProfile.local`; прежний провайдер —
   `legacyProviderIsLocal` (`ollama` всегда, как в снимке слота [[decision-40]]; `custom` — если адрес на
   localhost). В Swarm используется `providerInfo.local` снимка слота, в AI Studio — `local` цели запроса
   (`resolveOpenAICompatibleTarget`). Anthropic API и CLI-движки локальными не считаются.
3. **Одна таблица на процесс** — `pricingService` (main): встроенная таблица плюс переопределения из
   `<userData>/agent-pricing.json`. Ей пользуются Swarm (`agentFleetService`, `setPriceTable` остаётся для тестов),
   API-путь AI Studio (`aiAgentService.streamChat` считает стоимость итогового usage той же функцией, это же
   получает ревьюер Arena) и Claude CLI (`claudeBridgeService`). Сохранение из редактора атомарно (tmp + rename)
   и сразу меняет таблицу в памяти, перезапуск не нужен. Битый файл не ломает расчёт: действуют встроенные цены,
   UI показывает причину.
4. **Формат файла совместим с прежним**: `{ updatedAt, models: { <id>: { input, output, cacheRead?, cacheWrite?,
   source? } } }`, цены в USD за 1M токенов. `source` — `manual` или `openrouter`. Ключи нормализуются
   `normalizeModelId`, отрицательные и нечисловые цены отбрасываются (`sanitizePriceOverrides`, `mergePriceTables`).
   Встроенная таблица остаётся справочником в коде с датой актуальности, пользователь её не редактирует.
5. **Редактор цен** — вкладка «Цены» в настройках AI Studio (модалка уже рендерится с `z-[9999]`, [[decision-17]]).
   Встроенные, переопределённые и свои модели показаны раздельно с метками. Есть правка, сброс к встроенной цене,
   удаление своей модели, поиск и добавление модели. Сохранение — отдельной кнопкой, не вместе с настройками
   AI Studio. Строки ru и en.
6. **Импорт OpenRouter** — по кнопке, без ключа, в main-процессе (`fetchOpenRouterPrices`). Разбор —
   чистая функция `parseOpenRouterModels`:
   - USD за токен переводится в USD за 1M;
   - `input_cache_read`/`input_cache_write` переносятся в кэш;
   - варианты с `:` пропускаются: после нормализации `:free` перетёр бы цену платной модели;
   - цена `-1` пропускается;
   - из дублей нормализованного id берётся недатированная модель;
   - `pricing.overrides` не импортируется, пользователь видит число таких моделей.
   Импорт ничего не пишет сам: выбранные модели попадают в черновик переопределений с пометкой `openrouter` и
   сохраняются общей кнопкой.
7. **Usage OpenAI-совместимых серверов**: `usageFromOpenAI` читает `prompt_tokens_details.cached_tokens` (OpenAI,
   Ollama 0.34) и `prompt_cache_hit_tokens` (DeepSeek) в `cacheReadTokens`, `cost` OpenRouter — как `provider`.
   Пресет Ollama и прежний `ollama` получают `streamUsage: true`. Сохранённые профили не мигрируются: флаг
   включается в редакторе профиля.
8. **Без usage — оценка** `estimateUsage`: около 4 символов на токен по запросу (сообщения и описания tools) и
   ответу (текст, рассуждения, аргументы вызовов), пометка `estimated: true`, `costSource: 'unknown'`. В AI Studio
   оценка делается для каждого ответа модели без usage, в Swarm — для хода агента, если движок не сообщил usage
   (CLI без итоговой строки). У локального провайдера стоимость оценки — 0 (`local`). Карточка агента и экспорт
   показывают `~` у токенов и пояснение.

## Consequences

- Swarm, AI Studio и Claude CLI считают стоимость одной функцией по одной таблице, правка цен применяется сразу.
  Ревьюер Arena получает стоимость и у OpenAI-совместимых провайдеров.
- Локальные агенты больше не показывают «—»: карточка и экспорт выводят «$0.00 (локальная)», сводка сессии и
  бюджеты видят известную нулевую стоимость. У Ollama теперь реальные токены и кэш вместо `chars / 4`.
- Минус: `local` — утверждение пользователя в профиле. Удалённый Ollama в локальной сети с пометкой «локальный»
  тоже считается бесплатным. Это задумано: платит за железо пользователь, а не провайдер.
- Минус: тарифы длинного контекста (OpenRouter `overrides`, прежние модели Sonnet 4.x с 1M) не учитываются,
  цена по базовому тарифу может быть занижена на очень длинных запросах.
- Долг: облачные серверы (OpenAI, DeepSeek, OpenRouter) вживую не проверены, ключей нет. Разбор их usage
  покрыт unit-тестами на форматы из документации, импорт OpenRouter проверен вживую без ключа. Старые сохранённые
  профили Ollama со `streamUsage: false` продолжают давать оценку, пока пользователь не включит флаг.
- Реализация и тесты: TASK-70.4 (`electron/services/agentPricing.ts`, `pricingService.ts`, `src/lib/pricingEditor.ts`,
  `PricingEditorSection.tsx`; тесты `tests/unit/agentPricing.test.ts` с фикстурой ответа OpenRouter, дополнения
  `agentFleetPersistence.test.ts`, `llmProfiles.test.ts`, `openAICompatibleRequest.test.ts`, `swarmExport.test.ts`).
