## Description

ProjectHub как лучший агентный harness: работа с любой LLM (облачной или локальной) без привязки к вендору, нативные протоколы движков (Claude Code, Codex app-server), цикл «до готовности», автоматизации, память агента, чекпоинты, планировщик подзадач, экспорт ролей в нативные субагенты. См. doc-10.
