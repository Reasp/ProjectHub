# Core Architecture & Desktop Hub

## Описание
Первый ключевой этап разработки десктопного центра управления ProjectHub:
- Каркас Electron + Vite + React 19 + Tailwind v4
- Автоматическое сканирование и каталог проектов `ProjectTemplate`
- Интерактивная Канбан-доска с поддержкой `Backlog.md`
- Визуальный Git-инспектор с историей коммитов, ветками и диффами
- Управление Pull/Merge Requests (GitHub / GitLab)
- Полнотекстовый и семантический Vector RAG поиск (LanceDB)
- Менеджер фоновых процессов и живой терминал логов
- Модуль управления ADR (Архитектурные решения) и документацией
- Модуль управления майлстоунами и дорожной картой
