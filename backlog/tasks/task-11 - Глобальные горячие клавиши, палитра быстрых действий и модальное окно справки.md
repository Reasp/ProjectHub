# task-11: Глобальные горячие клавиши, палитра быстрых действий и модальное окно справки

## Description
Реализовать систему глобальных горячих клавиш (Keyboard Shortcuts) для быстрой навигации по вкладкам, создания задач, управления терминалом и вызова модального окна справки по шорткатам (`?` / `F1`).

## Acceptance Criteria
<!-- AC:BEGIN -->
- [x] #1 Глобальный хук перехвата горячих клавиш: `Ctrl+K` (поиск), `Ctrl+N` (новая задача), `Ctrl+Shift+P` (новый проект), `Ctrl+G` (Git), `Ctrl+B` (Backlog), `Ctrl+M` (Майлстоуны), `Ctrl+D` (Документы), `Ctrl+\` (терминал), `Ctrl+R` (обновить).
- [x] #2 Модальное окно шпаргалки по горячим клавишам `HotkeysHelpModal.tsx` с красивым оформлением клавиш (`<kbd>`).
- [x] #3 Вызов модального окна по клавише `?` (Shift+/) или `F1`, а также по кнопке справки в шапке (`Header.tsx`).
- [x] #4 Защита от срабатывания односимвольных шорткатов при вводе текста в `input`, `textarea` и markdown-редакторе.
<!-- AC:END -->
