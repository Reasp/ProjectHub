## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Сейчас языка голосового ввода в настройках нет: он всегда равен языку интерфейса. `VoiceControlWidget` при каждой смене языка (кнопки EN / RU в шапке, `Header.tsx`) вызывает `voiceService.setLanguage`, и тот сохраняет значение в `config.language`.

Из этого `config.language` берут язык:
- Whisper (`dispatchToWhisper` → `transcribeLocalWhisper(pcm, language)`, облачные провайдеры);
- Web Speech API (`recognition.lang` = `ru-RU` / `en-US`);
- классификатор команд и озвучка ответов (`speakLang`).

Как это мешает:
- При интерфейсе на EN русская речь не распознаётся как русская: Whisper переводит её на английский. Говорить по-русски при английском интерфейсе нельзя.
- Нельзя диктовать по-английски, не переключая весь интерфейс.
- Нет автоопределения языка, хотя Whisper его умеет.

Нужно: в настройках голоса (`VoiceSettingsModal`) выбор «Язык распознавания» с вариантами «Как интерфейс» (по умолчанию, нынешнее поведение), «Русский», «English», «Автоопределение» (если провайдер Whisper его поддерживает; для Web Speech API автоопределения нет — показать подсказку и откатиться на язык интерфейса).

Выбранный язык распознавания нельзя смешивать с языком интерфейса: смена EN / RU в шапке не должна перезаписывать явный выбор. Нужно решить, по какому языку работают:
- разбор команд регулярками (фразы команд из `voiceCommandPhrases`);
- классификатор (`voice:classifyCommand`, поле `language`);
- язык озвучки ответа.

Разумный вариант — язык распознанной фразы, если Whisper его вернул, иначе язык распознавания, иначе язык интерфейса. Выбор зафиксировать в ADR.

Миграция: у существующих пользователей `config.language` уже хранит язык интерфейса. Новое поле (например, `recognitionLanguage: 'ui' | 'ru' | 'en' | 'auto'`) по умолчанию `ui`, чтобы поведение не поменялось само.
<!-- SECTION:DESCRIPTION:END -->

## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
### Реализация

- **Настройка `recognitionLanguage`** (`ui | ru | en | auto`, по умолчанию `ui`): «Настройки голоса» → «Распознавание», под выбором движка. Переключатель EN / RU в шапке меняет только `config.language`. Старые настройки без поля нормализуются в `ui`.
- **Чистый модуль `src/services/voiceLanguage.ts`:**
  - `resolveRecognitionRequest` — язык запроса к движку;
  - `resolvePhraseLanguage` — язык фразы: сообщённый движком → явный → алфавит текста → интерфейс;
  - `detectTextLanguage` — по алфавиту, русский при кириллице от 30% букв;
  - `speechLanguageForText` — язык озвучки по тексту.
- **Автоопределение локального Whisper.** transformers.js сам язык не определяет: без языка подставляет en. Определяю одним шагом декодера после `<|startoftranscript|>` по логитам `<|ru|>`/`<|en|>` (`electron/workers/whisperLanguage.mjs`, `pickWhisperLanguage`). При отрыве < 3 берётся язык интерфейса. Воркер возвращает язык вместе с текстом.
- **Облачный Whisper** при `auto` уходит без `language`.
- **Web Speech API** при `auto` слушает на языке интерфейса, в настройках показывается подсказка.
- **Классификатор** получает язык фразы; в промпте — «язык фразы» вместо «язык интерфейса».
- **Озвучка:** `speak()` без явного языка выбирает голос по языку текста (ответ агента, итог задачи «голос → компьютер»). Строки интерфейса — на языке интерфейса.
- Регулярки команд от языка не зависят: фразы обоих языков в одном списке.

## Final Summary

- **Автоопределение для локального Whisper** сделано своим шагом декодера: transformers.js сам язык не определяет. Облачный Whisper получает запрос без языка.
- **Web Speech API** при «Автоопределении» слушает на языке интерфейса, настройки показывают подсказку.
- **Язык фразы** (сообщённый движком → явный → алфавит текста → интерфейс) идёт в классификатор.
- **Озвучка** подбирает голос по языку текста.
