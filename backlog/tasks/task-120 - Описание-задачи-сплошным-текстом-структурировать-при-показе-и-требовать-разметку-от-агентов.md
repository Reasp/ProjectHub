## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
### Проблема

Агенты часто пишут описание задачи одной строкой без переносов: метки `**Исполнитель:**`, `**Почему:**`, `Цель:` идут подряд внутри одного абзаца. В окне задачи ProjectHub такое описание выглядит сплошной стеной текста, хотя `MarkdownViewer` умеет заголовки, списки и абзацы.

### Что делаем

1. **Показ.** Чистая функция структурирует сплошные абзацы только для отображения: метки выносит в заголовки, длинный текст делит на абзацы по предложениям. Файл задачи не меняется, режим редактирования показывает исходный текст.
2. **Агенты.** В промпт планировщика и в правила агентов (`infra-dev.md`) добавляется требование писать описание с заголовками, списками и абзацами.

### Вне рамок

Автоматическая перезапись файлов задач и вызов модели для форматирования.
<!-- SECTION:DESCRIPTION:END -->
