## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
### Почему

[[decision-69]] оставило два долга (раздел Consequences):

- Карточка задачи с несохранёнными правками закрывается без вопроса крестиком, клавишей `Escape` и кликом по фону — случайное нажатие стирает набранное описание. После [[TASK-122]] правки защищены только при переходе по ссылке. Кнопки «В Swarm Arena», «До готовности» и открытие сессии из плана тоже закрывают карточку.
- Блок «На этот документ ссылаются» не показывает факты памяти проекта ([[decision-51]]), хотя факт часто объясняет, почему решение принято, и ссылается на него.

Попутно: `Escape` в диалоге подтверждения, открытом поверх карточки, закрывает и диалог, и карточку — оба слушают клавишу на `window`.

### Цель

- Случайное закрытие карточки не стирает правки.
- Факты памяти видны среди обратных ссылок документа и открываются по клику.

### Ограничения

- Кнопка «Отмена» в карточке — явный отказ от правок, вопроса не задаёт.
- Задачи из `backlog/completed` и обратные ссылки на задачу в объём не входят.
- Если `ProjectHub.exe` запущен, `pack:win` не обновит exe: проверять свежий `dist-electron` через `node_modules/electron/dist/electron.exe` с отдельным `--user-data-dir`, приложение владельца не закрывать.

## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
### Что сделано

- **Закрытие карточки**: `requestClose` в `TaskDetailModal` спрашивает подтверждение, если форма отличается от записанного в файл. Через неё идут крестик, `Escape`, клик по фону, кнопки «В Swarm Arena» и «До готовности», открытие сессии из плана. «Отмена», сохранение и удаление закрывают напрямую.
- **Escape**: карточка не реагирует, если открыт диалог `DialogHost` или событие уже обработано. Это чинит и диалог перехода по ссылке из TASK-122: раньше `Escape` в нём закрывал карточку.
- **Память**: `buildProjectDocLinkIndex` читает `backlog/memory/mem-N - ….md`, вид источника `mem`, в блоке идёт после задач со значком памяти.
- **Решение**: decision-70; долги в decision-69 помечены. `index-docs` выполнен.
