## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Сохранение размера и геометрии окна между запусками, персистентность активных вкладок и фильтров, graceful fallback заглушка при удалении проекта и гарантированное выключение микрофона при старте.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [x] #1 Размер, позиция и статус максимизации главного окна Electron сохраняются между перезапусками приложения
- [x] #2 Активная вкладка рабочей области (activeTab) и фильтры (теги, майлстоуны, режим канбан/список, избранное, PR-фильтр) сохраняются в localStorage и восстанавливаются при старте
- [x] #3 Если ранее выбранный проект был удален или отсутствует, приложение переходит в состояние заглушки без краша и отображает информативный Empty State
- [x] #4 Голосовой ввод гарантированно запускается в выключенном состоянии (idle) и не авто-стартует при запуске приложения
<!-- AC:END -->
