# task-3: Интерактивная доска задач и просмотрщик Backlog (Kanban, List, Task Details)

## Description
Создать визуальный интерфейс управления задачами проекта с интерактивной Канбан-доской, списком задач, фильтрацией и возможностью редактирования markdown-файлов задач.

## Acceptance Criteria
- [x] Канбан-доска с колонками `To Do`, `In Progress`, `Review`, `Done`.
- [x] Drag-and-Drop перетаскивание задач между колонками с автоматической перезаписью поля `status` в frontmatter файла `backlog/tasks/*.md`.
- [x] Поддержка правил перевода статусов (например, предупреждение при попытке перевести задачу сразу в `Done` минуя `Review`).
- [x] Детальная карточка задачи:
  - Просмотр и редактирование описания задачи в Markdown с подсветкой и превью.
  - Управление Acceptance Criteria (интерактивные чекбоксы).
  - Управление тегами/лейблами.
- [x] Кнопка быстрого создания новой задачи с автоматической генерацией ID (`task-N`).
- [x] Отслеживание изменений файлов через `chokidar` (если файл задачи изменил агент или IDE, UI мгновенно обновляется без перезагрузки).
