# task-6: Модуль глобального и локального RAG-поиска по документации проектов

## Description
Реализовать единый поисковый интерфейс по базе знаний (markdown документация, ADR решения, задачи) с поддержкой семантического векторного поиска через LanceDB.

## Acceptance Criteria
- [x] Окно быстрого поиска по горячей клавише `Ctrl + K` (Omni-search).
- [x] Два режима поиска:
  1. Текстовый полнотекстовый поиск по названиям проектов, задач и документов.
  2. Семантический Vector RAG поиск (интеграция со `scripts/rag/search-cli.mjs` или прямым запросом к таблице LanceDB).
- [x] Отображение результатов с фрагментами найденного текста (snippets), названием проекта и быстрой навигацией к соответствующей задаче или документу.
- [x] Кнопка переиндексации документации проекта (`npm run index-docs`) прямо из UI с отображением прогресса.
