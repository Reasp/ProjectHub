---

## 1. Обзор проекта (Executive Summary)

**ProjectHub** — это автономное мультиплатформенное десктопное приложение (Desktop Dashboard / Control Center), решающее проблему разрозненного управления множеством локальных проектов с AI-агентной инфраструктурой.

Каждый проект пользователя содержит обвязку на базе `ProjectTemplate`:
- `backlog/` — файловая система управления задачами, майлстоунами, решениями (ADR) и документацией (`Backlog.md`).
- `scripts/rag/` — коммитимый векторный поиск по документации (LanceDB + HuggingFace Transformers).
- `scripts/env/` — менеджер фоновых локальных процессов и dev-серверов.
- `.agents/` и `.claude/` — правила, скиллы и конфигурация MCP-серверов для AI-агентов (Antigravity, Claude Code).

**ProjectHub** объединяет все эти проекты в единый графический интерфейс без необходимости держать открытыми десятки вкладок браузера или консолей.

## 2. Ключевые возможности и функциональные блоки

```
+-----------------------------------------------------------------------------------+
|                                  PROJECT HUB                                      |
+-----------------------------------------------------------------------------------+
|  [Sidebar]             |  [Main Content Area]                                     |
|  - Все проекты (List)  |  +----------------------------------------------------+  |
|  - Избранные           |  | Заголовок проекта, Git: main (ahead 1), Dev: 3000  |  |
|  - Активные задачи     |  +----------------------------------------------------+  |
|  - Глобальный RAG-поиск|  | [Вкладки]:                                         |  |
|  - Git & PRs обзор     |  |  1. Задачи (Kanban / List / Спринты)               |  |
|  - Настройки Hub       |  |  2. Git Репозиторий (Graph / Diffs / Branches)     |  |
|                        |  |  3. Merge / Pull Requests (Review / Create / CI)   |  |
|  [Кнопки]:             |  |  4. Документация & ADR (Markdown Viewer/Editor)   |  |
|  + Добавить проект     |  |  5. Процессы & Dev-серверы (Логи в реальном времени)|  |
|  + Создать из шаблона  |  |  6. RAG-поиск & Граф знаний                       |  |
+------------------------+----------------------------------------------------------+
```

1. **Discovery & Workspace Manager (Каталог проектов)**:
   - Автоматическое сканирование каталогов (например, диск `F:\`, пользовательские директории) и обнаружение проектов со структурой `ProjectTemplate` (`backlog/`, `infra.config.json`, `.git`).
   - Добавление локальных папок вручную (через нативный File Dialog).
   - Отображение карточки проекта: статус Git (ветка, uncommitted files, ahead/behind), сводка задач (To Do / In Progress / Review / Done), активность dev-серверов, статус индекса RAG.

2. **Инициализация новых проектов (New Project Wizard)**:
   - Мастер создания проекта из `ProjectTemplate` в 1 клик.
   - Выбор пути, названия, включение опциональных фич (`docsRag`, `envTools`, `backlogMcp`, `bootstrap`, `lightrag`).
   - Автоматический запуск `setup.mjs`, инициализация локального git-репозитория и синхронизация MCP-конфигов.

3. **Интерактивный менеджер задач (Backlog Management)**:
   - Просмотр и редактирование задач проекта в виде Канбан-доски (To Do → In Progress → Review → Done) и списков.
   - Drag-and-drop перемещение задач между колонками с обновлением файлов `backlog/tasks/*.md`.
   - Создание и редактирование задач с поддержкой markdown-форматирования, майлстоунов и тегов.
   - Управление майлстоунами (`milestones/`) и архитектурными решениями (`decisions/`).

4. **Просмотр Git-репозитория (Git Graph & Diff Viewer)**:
   - Визуализация графа истории коммитов (как в SourceTree / GitKraken).
   - Дерево веток (локальные и remote), теги, стэши (stashes).
   - Просмотр изменений рабочей директории (Working Copy Diff) построчно/side-by-side.
   - Базовые Git-операции: переключение веток, создание новой ветки под задачу Backlog (например, `feat/task-3`), стэш, создание коммитов с привязкой к ID задачи.

5. **Управление Merge / Pull Requests (PR & Code Review Hub)**:
   - Интеграция с GitHub API (`gh` CLI / Octokit) и GitLab API.
   - Список открытых и закрытых Pull/Merge Requests по проектам.
   - Просмотр диффа PR, описания, статуса CI/CD проверок и комментариев ревьюеров.
   - Создание нового PR из текущей ветки задачи в 1 клик с автогенерацией описания на основе бэклога (`backlog/tasks/task-N.md`).
   - Синхронизация статусов: автоматический перевод задачи Backlog в статус `Review` при открытии PR и в `Done` при слиянии (merge).

6. **Процессы и Dev-окружение (Process Control & Log Streaming)**:
   - Интеграция с локальным `env-server` / `process-manager.mjs`.
   - Запуск/остановка dev-серверов, сборщиков, бэкендов в один клик.
   - Встроенная консоль вывода логов процессов с подсветкой синтаксиса.

7. **Единый центр документации и RAG-поиск (Unified Docs & Search)**:
   - Чтение и быстрый поиск по документации проекта.
   - Глобальный или локальный RAG-поиск по векторным индексам проектов.

## 3. Выбранный технологический стек

- **Платформа десктопа**: **Electron + Vite + React 19 + TypeScript**
  - *Обоснование*: Полная нативная совместимость с Node.js runtime (прямой вызов `isomorphic-git` / `simple-git`, `@modelcontextprotocol/sdk`, `@lancedb/lancedb`, `node:child_process` без сторонних прослоек и компиляторов).
- **Git & Diff Движок**: **simple-git** / **isomorphic-git** + **@git-diff-view/react** / **monaco-diff-editor** (построчный и side-by-side просмотр диффов, визуализация ветвления).
- **Стилизация и UI-система**: **Tailwind CSS v4 + Lucide React Icons + Radix UI Primitives** (премиальный темный интерфейс в стиле современной IDE / Linear / SourceTree).
- **Управление состоянием**: **Zustand** + **TanStack Query** (локальный кэш файловой системы, git-статусов и процессов).
- **Работа с файлами и задачами**: Нативный модуль парсинга YAML Frontmatter + Markdown (на базе `gray-matter` и `marked`/`unified`), совместимый с форматом `Backlog.md`.
